# Fitlog

Fitlog is a workout application that helps users discover workouts, create a daily workout plan, save exercises, and track their progress.

## Features

- Browse workout library
- View workout details
- Add workouts to Today's Plan
- Save workouts for later
- Mark workouts as completed
- Remove workouts from the plan
- Track total exercises, minutes, and calories
- Sort workouts
- Responsive design

## Technologies

- Next.js
- React
- TypeScript
- CSS Modules
- Context API
- JSON
